Entry for the [make.fun](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty **"One Letter for Your Day"** — send exactly one letter, A to Z, standing for the word that describes your day.

## The letter

**C** — for **chaos**. Today was a day of joyful chaos: a dozen bounty builds fired off back-to-back, every one a small race against its own deadline. Chaos is the truest word for the day.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly one character to `/output/entry.txt`:

```sh
node main.ts
```

The output is a single byte, `C` — deterministic and byte-identical on every run, satisfying the gate (UTF-8 text of exactly 1 character, A–Z).
